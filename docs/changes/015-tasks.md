# 015 — Tutorial guiado (tour)

Tour que escurece a página e destaca onde informar os dados e onde ver os resultados.

- [x] `driver.js` (MIT, empacotado no site; sem requisições externas)
- [x] Seis passos: boas-vindas, Carreira, Descontos, Aposentadoria, Previdência e o menu de abas
      ("Temos mais opções para você ver mais detalhes"); alvos marcados com `data-tour`
- [x] Uma única instância do tour, reaproveitada (evita balões sobrepostos)
- [x] Início automático após o aceite do aviso na primeira visita; botão "Ver tutorial"; estado no `localStorage`
- [x] Visual com os tokens do app; verificação no navegador (desktop e celular, claro e escuro)
